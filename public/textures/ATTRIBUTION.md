Link "Solar System Scope" to the source page and "CC BY 4.0" to the license.
If resizing, recoloring, or otherwise modifying these downloaded files, indicate those changes alongside the credit.

The source describes the planet maps as equirectangular, based on NASA elevation and imagery data, with colors informed by spacecraft imagery. It notes that unmapped gaps may contain fictional terrain and that colors are somewhat more saturated than reality.

Downloads are unmodified. All requested assets were available on 2026-09-14.

All 2k planet maps: 2048 x 1024 JPEG.
8k Earth day and cloud maps: 8192 x 4096 JPEG.
Saturn ring: 2048 x 125 RGBA PNG, with transparency.
Earth cloud maps are opaque JPEGs: use luminance as an alpha mask rather than expecting embedded alpha.
